PROJECT 01 / 04

HR Analytics Dashboard

1,417 Employees 16.3% Attrition 231 Departures 1,186 Active

Built an interactive Power BI workforce analytics dashboard analyzing 1,417 employee records. Evaluated attrition rates (16.3%), salary slab trends, demographic patterns, job satisfaction levels, and departmental turnover to uncover workforce retention drivers.

Power BI DAX Power Query HR Analytics
View on GitHub → View Dashboard →

Project Overview

An interactive HR Analytics Dashboard developed using Power BI to analyze employee demographics, attrition rates, compensation tiers, tenure, departmental distribution, job roles, and satisfaction metrics.

Designed to equip HR leaders and business partners with centralized workforce intelligence for monitoring staff retention, identifying disproportional department departures, and driving proactive talent management.

1,417 Total Employees
1,186 Active Employees
231 Attrition Count
16.3% Attrition Rate

Project Objectives

Demographic Mapping: Analyze overall workforce distribution across age cohorts and gender balance.
Attrition Monitoring: Monitor net employee departures and measure the baseline attrition rate.
Department Risk Analysis: Identify departments experiencing elevated turnover rates.
Compensation & Gender Audits: Analyze turnover trends across salary slabs and gender representations.
Job Satisfaction Correlation: Gauge attrition frequency against role-specific satisfaction ratings.
Tenure Analysis: Understand how years of experience correlate with employee retention.

Dashboard Analysis Dimensions

Employee Demographics

Evaluates age brackets, gender ratio, and department-wise headcount to map workforce composition.

Employee Attrition

Examines turnover rates partitioned across departments, salary slabs, gender, and individual job roles.

Job Satisfaction Index

Cross-examines job roles and satisfaction rankings against voluntary and involuntary departure trends.

Experience & Tenure

Tracks attrition against total years of professional experience, revealing retention patterns over employee life cycles.

Key Insights & Findings

16.3% Attrition Rate: 231 employees left out of 1,417 total personnel across the organization.
Highest Department Departures: Administration had the highest attrition volume with 84 employees, followed by Sales (52) and Operations (43).
High Sales Turnover Rate: Sales had the highest relative attrition rate relative to department size at approximately 25.1%.
Primary Age Cohort: Employees aged 26–35 constitute the largest age segment with 588 employees.
Compensation Tier Vulnerability: The 6–10 LPA salary group had the highest attrition count (73 employees).
Gender Distribution in Turnover: Male employees accounted for 63.2% of attrition (146 staff) compared with 36.8% (85 staff) for female employees.
Largest Department: Operations is the largest department with 512 total employees.
Tenure Concentration: Attrition was notably concentrated among employees with fewer years of overall experience.
Workforce Demographics: The average employee age is 36.94 years with an average experience of 7.04 years.

PROJECT 03 / 04

Layoffs Data Cleaning Using SQL

2,361 → 1,995 Rows 366 Rows Removed 0 Duplicates Left 100% Staged

Cleaned and standardized 2,361 company layoff records using MySQL. Built non-destructive staging tables, purged 366 duplicate records via ROW_NUMBER() and PARTITION BY, handled missing values, and validated data integrity for downstream analytics.

MySQL Window Functions Data Cleaning SQL
View on GitHub → View Query Results →

Project Overview

This project focuses on cleaning a real-world layoffs dataset using MySQL. The primary objective was to eliminate noise, handle null values, and standardize data types to ensure data consistency and reliability before downstream analytical modeling.

To uphold data engineering best practices, staging tables were created so that the original raw records remained untouched and auditable throughout the entire cleaning process.

2,361 Original Rows
1,995 Cleaned Rows
366 Rows Removed
0 Duplicate Groups

Dataset Fields Handled

Company Location Industry Total Laid Off Percentage Laid Off Date Company Stage Country Funds Raised

Data Cleaning Process

01
Created Staging Tables

Created copies of the original dataset before transforming data, preserving raw data integrity.

02
Identified Duplicate Records

Used the ROW_NUMBER() window function partitioned across all key dimensions to detect identical entries.

03
Removed Duplicates

Deleted duplicate rows where row_num > 1, successfully pruning redundant records.

04
Standardized Text Data

Applied TRIM() to company names, normalized fragmented industry labels (e.g. Crypto categories), and stripped trailing periods from country values.

05
Standardized Dates

Converted date text values into native MySQL DATE data types using STR_TO_DATE() for time-series compatibility.

06
Handled Missing & Blank Values

Converted blank strings to NULL, and cross-referenced same-company entries via joins to impute missing industry attributes.

07
Purged Incomplete Records

Filtered out rows where both total_laid_off and percentage_laid_off were missing and unrecoverable.

08
Validated the Cleaned Dataset

Audited duplicate counts, schema types, remaining nulls, and final row distributions.

Project Overview

Northstar is a production-style Django web application designed to centralize employee records, departmental structures, workforce reports, and day-to-day administrative operations in one unified workspace.

Engineered for ease of use by HR teams and administrators, the interface emphasizes a dashboard-first layout with clear sidebar navigation, live search, multi-field filtering, automated phone/salary normalization, and staff-only protected administrative controls.

Django 5.2 Web Framework
Python 3.13+ Core Runtime
MySQL Database Backend
RBAC Staff vs. Viewer Roles

Core Application Modules

Executive Dashboard

Summarizes active employee headcount, department allocations, compensation totals, and recent hiring activity at a glance.

Employee Directory

Interactive table equipped with real-time text search, department filtering, multi-column sorting, pagination, and modal profile views.

Department Overview

Breaks down organization units with live headcount counts, average salary metrics, and latest hire records.

Workforce Reports

Dedicated analytics page displaying hiring velocity trends, salary range distributions, and department ratio summaries.

Key Features & Engineering Details

Full CRUD Management: Add, edit, review, and securely delete employee profiles with strict model-level validations.
Staff-Only Bulk Actions: Perform efficient multi-selection bulk deletions guarded by Django CSRF tokens.
One-Click CSV Export: Instantly export employee datasets for offline auditing, payroll integration, and executive reporting.
Django Authentication & RBAC: Role-based access control where staff users hold administrative rights and regular users have read-only access.
Localization & Input Validation: Automated Philippine mobile number normalization to +639... and Philippine Peso (₱) salary formatting.
Media & Contact Handling: Secure profile picture uploads processed using Pillow, alongside emergency contact cards and administrative notes.
Polished UI/UX: Fully responsive interface featuring a branded sidebar, custom browser favicon, and sleek dark styling.
